# Beacon Computing Initiative — BCILock

**Developer Seal:** CJB-DEV-2026

BCILock is a Linux and Android endpoint-security project
combining Bluetooth device verification, cryptographic
authentication, desktop locking, and network egress enforcement.

## Components

- Kali Linux desktop controller
- Android authentication application
- Bluetooth Low Energy authentication bridge
- Network egress enforcement
- Desktop lock integration
- Verification and deployment tooling

## Security

Device private keys, enrollment secrets, local credentials,
and runtime telemetry must not be committed.
